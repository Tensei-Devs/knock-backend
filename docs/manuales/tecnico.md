# Manual del técnico

Borrador para revisión del equipo sobre `sprint-05`.

## Revisar y cotizar solicitudes

1. Inicia sesión con una cuenta de técnico habilitada y abre **Trabajo**.
2. Revisa **Solicitudes nuevas**. Abre una tarjeta para leer el problema, la colonia y la franja que prefiere la persona.
3. Si puedes atenderla, captura el precio o rango, el día y la hora. Revisa la nota y envía la cotización. Consulta el resultado en **Cotizaciones enviadas**.
4. Revisa **Próximas visitas** y abre el detalle de una cita confirmada para saber dónde y cuándo atenderla.

## Datos de la visita

Usa la información de contacto y la dirección para atender la cita correspondiente. Para documentar el flujo, usa una cuenta de semilla y fotos ficticias. La verificación y la reputación se consultan desde **Trabajo**.

Capturas pendientes con un técnico de semilla: bandeja, cotización enviada y agenda.
