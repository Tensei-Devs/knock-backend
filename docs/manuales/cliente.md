# Manual del cliente

Borrador para revisión del equipo sobre `sprint-05`.

## Buscar y pedir una cotización

1. Entra a Knock e inicia sesión con tu número de celular. Completa tu zona para que la búsqueda y las solicitudes usen la colonia correcta.
2. Desde Inicio o Explorar, abre el oficio que necesitas o busca por texto. Abre un perfil para revisar su información pública.
3. Al pedir una cotización, elige el oficio y describe el problema. Agrega de una a cinco fotos del trabajo. Para el recorrido de prueba se necesita una compilación conectada a la API con subida privada habilitada.
4. Elige el día y la franja. Si el servicio es a domicilio, selecciona una dirección. Revisa los datos y pulsa **Enviar solicitud** una vez.

## Seguir la solicitud

- En **Actividad**, abre la solicitud para revisar su estado y las cotizaciones. Compara su alcance, precio y horario antes de elegir.
- Si la solicitud admite cancelación, abre el detalle, pulsa **Cancelar solicitud** y confirma. Revisa el estado al volver a Actividad.
- En **Mensajes**, abre la conversación disponible. Si el envío falla, revisa la conexión y el estado de la solicitud antes de reintentar.
