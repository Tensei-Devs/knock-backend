# Módulo de Terraform de Azure Front Door (KNOCK-296)

## Qué cambió
`deploy/modules/edge` y `deploy/edge/` (estado propio `edge.tfstate`): Front Door Standard con una ruta al gateway (`/api/*`, `/health`) y rutas opcionales para el contenido estático del panel y la landing y para las imágenes públicas. Pruebas con proveedor simulado (`terraform test`, 3 casos). El README de `deploy/edge/` trae los pasos exactos para aplicar, verificar y destruir, y el costo para unos pocos días. El ADR-007 refleja que sí habrá CDN, marcada como preparada y sin aplicar.

## Por qué
Los lineamientos piden una CDN (punto 15c). Azure CDN classic ya no admite perfiles nuevos; Front Door Standard es lo que se puede crear. Se prepara el módulo sin desplegarlo: el apply lo hace el Tech Lead después del primer despliegue exitoso y de la evidencia.

## A evitar
No aplicar el módulo desde el CI. No decir que la CDN está implementada hasta confirmar el apply. No enrutar tráfico real por Front Door: el gateway sigue como entrada principal. No pasar por el borde las fotos de verificación ni contenido privado.
